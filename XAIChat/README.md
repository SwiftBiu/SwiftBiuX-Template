# xAI Chat

This plugin demonstrates how a text action binds to SwiftBiu AI Provider model selection.

- `ai.useCase`: `chat`
- default provider: `xai-oauth`
- default model: `grok-4.3`
- host bridge: `SwiftBiu.aiChat`

After installing the plugin, open its settings and choose an xAI text model. The action sends the selected text to the configured model and pastes the response.

# Image to SVG (ImageTracer)

Standalone SwiftBiuX plugin. It does **not** change the SwiftBiu app binary.

Bundles [ImageTracer.js](https://github.com/jankovicsandras/imagetracerjs) (Unlicense), [UPNG.js](https://github.com/photopea/UPNG.js), and pako inflate. Select a PNG and run **Convert with ImageTracer**. Settings are in the extension configuration. No Web UI and no network.

PNG only. JPEG/HEIC are not decoded inside JavaScriptCore.
